# Getting Started

Welcome to Rust!

Rust is a systems programming language focused on safety, speed, and concurrency.

## Install Rust

Install Rust using rustup.

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
