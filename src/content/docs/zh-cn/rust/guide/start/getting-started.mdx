# Rust 入门

欢迎来到 Rust 学习之旅！

Rust 是一门注重安全性、速度和并发性的系统编程语言。它通过所有权系统和严格的类型检查，在不依赖垃圾回收机制的情况下保证内存安全。

## 安装 Rust

Rust 官方推荐使用 `rustup` 安装和管理 Rust 工具链。

在 Linux 或 macOS 上执行：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
